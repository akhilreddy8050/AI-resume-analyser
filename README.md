# AI Resume Analyser

An AI-powered tool that analyzes resumes and matches them with job descriptions using NLP.

### 🚀 Features
- Upload Resume (PDF)
- Extract Skills, Education, Experience
- Job Description Matching
- ATS Score Calculation
- Streamlit Web Interface

### 🛠️ Tech Stack
Python, Streamlit, PyPDF2, scikit-learn, NLP
